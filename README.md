# Mercian Wealth — AI Automation & Digital Systems Platform

**Mercian Wealth** is a UK-based AI automation and digital systems provider engineered for local service businesses, high-end trades, food artisans, and service operators.

We build high-converting digital storefronts, 3-tap order builders, automated deposit collection engines, instant WhatsApp phone alerts, and 5-star Google review collection engines deployed in under 7 days.

## 🛠️ Architecture & Tech Stack

* **Framework**: Next.js 16.2 (App Router) & React 19
* **Styling**: Tailwind CSS v4 & Framer Motion
* **Database & Auth**: Supabase PostgreSQL with Server-Side Row Level Security (RLS) and Auth SSR (`proxy.ts`)
* **Payments & Deposits**: Stripe Checkout & Instant Deposit Gateways
* **Alert Infrastructure**: Sub-60s WhatsApp Phone Notifications & Webhooks
